# RGB_Matrix
The purpose of this project was to create a 24x12 Panel of RGBW Leds to create ambient or accent lighting on a wall behind a desk. 

The RGBW use a one-wire protocol, but the option to disconnect the chain of LEDs is available in 48 LED iterations in order to reduce latency, but at the cost of another control signal

The RGBW LED Matrix designed for a 1 layer PCB so that it has the availability to be constructed from Aluminum as opposed to an FR-4 base for better heat distribution
